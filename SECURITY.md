# 🛡️ Security Policy

## Supported Versions
Security updates are applied to the `main` branch.

| Branch | Supported |
| :--- | :---: |
| `main` | ✅ |

## Reporting Vulnerabilities
If you discover a security vulnerability or misconfiguration in these Terraform infrastructure blueprints, please report it responsibly by opening a private security advisory or contacting the maintainer via GitHub issues with the `security` label.

Please include:
* Module path and affected resource type
* Potential impact and attack vector
* Suggested remediation or Terraform HCL patch
